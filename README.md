# hailo10h-frigate-genai-descriptions

Done in python 3.10

## Download the model
Install the hailo-download-resources app with the repository https://github.com/hailo-ai/hailo-apps

```bash
git clone git@github.com:hailo-ai/hailo-apps.git
cd hailo-apps
pip install -e .
hailo-download-resources --arch hailo10h --group vlm_chat
```
